# 全国总决赛技术文档目录框架（建议稿）

## 一、编排结论

本框架面向全国总决赛，不沿用分赛区决赛的“裸机测试程序运行时间”叙事。全文主线建议统一为：

> 赛题约束与目标 → 自研 CPU 与 SoC → RT-Thread 系统支撑 → FPU 与应用扩展 → 分层验证 → 性能、时序与资源证据 → 创新总结

去年一等奖文档值得保留的不是具体章节名称，而是“快速给出成果—解释硬件系统—证明操作系统可运行—给出性能结果—突出进阶指标”的证据链。你们当前文档中已经较完整的 CPU 微架构内容应当保留，但需要压缩逐模块说明，补齐 SoC、RT-Thread、FPU、系统应用和板级证据，使其成为全国总决赛版本。

明确不纳入正文：现场程序快速接入、外部赛题源码接入脚本、bitstream 快速替换流程及相关操作手册式内容。

资料边界：当前本地的《比赛要求（2026 年 4 月）》能够确认本届 RV32I、地址空间、接口和读写时序等硬性技术约束，但其中没有 2026 全国总决赛评分表。因此，本框架只把去年全国总决赛一等奖材料和去年的总决赛评分要求作为结构参考，不把去年的分值或条款冒充为本届正式规则。收到 2026 全国总决赛最新通知后，应优先更新第 1.2、1.3 节和附录 A 的符合性矩阵。

# 1 项目概述与赛题要求

## 1.1 赛题背景与全国总决赛任务定位

说明作品面向 RISC-V CPU、FPGA 实现、操作系统运行和性能测评。不要把分赛区的 SRC 裸机用时写成全国总决赛的最终目标；SRC 可作为处理器演进阶段的验证与优化基线。

## 1.2 本届赛题硬性约束

- IROM 组合/同步访问口径与外设读写时序；

建议只写 4～6 项，并与后文章节一一对应：

3. Load Queue、Store Buffer、Store-to-Load 转发和 DCache 组成的访存系统；
4. RV32IMFD、FPnew FPU、FPR/FCSR 与 RT-Thread 浮点上下文支持；
5. HXI 双 Master SoC、Machine Mode 中断体系与 RT-Thread v5.2.2 移植；
